# Handoff de diseño — Traker Metas

Esta documentación describe cada pantalla y elemento de Metas desde la perspectiva del producto. Está pensada para que Claude Design pueda proponer un rediseño entendiendo el objetivo, el contenido, las acciones y los estados necesarios.

## Identidad que debe conservarse

- Experiencia mobile-first, adaptable a escritorio.
- Identidad: **Aurora 2**, serena, humana y atmosférica; base azul carbón con azul eléctrico, coral, violeta, cian y ámbar usados por función.
- Tipografía: Outfit para la interfaz e Instrument Serif sólo en momentos emocionales como regreso, bienvenida y estados vacíos.
- Iconografía lineal, consistente y sin emojis decorativos.
- Lenguaje sin culpa: no usar rachas, deuda, fracaso, atraso ni días perdidos.
- Metas funciona offline; la nube es opcional y requiere consentimiento explícito.
- La ausencia de actividad nunca cambia estados automáticamente.
- Metas y Hábitos comparten Aurora 2, pero se diferencian: las Metas usan dirección, siguiente paso y sesiones; los Hábitos usan registro diario y progreso flexible.

## Pantallas

| Pantalla | Descripción |
|---|---|
| Dashboard / Hoy | Meta prioritaria, resumen diario y lista de Hábitos. |
| Detalle de Hábito | Identidad, progreso, registro diario y administración. |
| Progreso general | Resumen e información útil de todos los Hábitos. |
| Listado de Metas | Consulta y acceso a las metas. |
| Crear o reformular | Creación de una meta y su primera acción. |
| Detalle y continuidad | Estado, siguiente paso e historial de una meta. |
| Sesión de trabajo | Concentración temporal en una acción. |
| Foco, privacidad y nube | Priorización, sincronización y consentimiento. |
| Meta prioritaria en Hoy | Integración de una meta dentro del dashboard. |
| Acceso desde Ajustes | Entrada resumida a la configuración de Metas. |

## Elementos reutilizables

- Acción prioritaria en Hoy.
- Tarjeta de siguiente paso.
- Formulario de acción.
- Trayectoria de progreso.
- Selector de esfuerzo.
- Selector de versión mínima.
- Regreso a una Meta.
- Privacidad y sincronización.

## Cómo usar la documentación

Entrega a Claude Design la descripción de la pantalla o elemento que quieras rediseñar. Pídele una propuesta visual que mantenga todos los contenidos, acciones, estados y restricciones indicados. Puede cambiar composición, jerarquía, espaciado, color secundario y microinteracciones, pero no el comportamiento funcional sin una decisión explícita de producto.
