# Elemento: retorno a una Meta

## Objetivo

Recibir a una persona que vuelve después de una pausa y ofrecer una entrada segura para retomar. Sólo debe aparecer cuando exista una pausa o ausencia real que justifique el mensaje.

## Debe contener

- Un encabezado cálido, por ejemplo «Qué bueno que volviste».
- Una explicación breve que no sugiera deuda acumulada.
- Contexto opcional sobre la Meta o el punto de retorno.
- Una acción principal para elegir cómo retomar; si no existe una acción útil, no mostrar un botón vacío.
- Un estado de preparación que evite activaciones repetidas.

## Estados a diseñar

- Mensaje y acción.
- Mensaje, contenido contextual y acción.
- Procesando.
- Sólo mensaje.
- Texto largo y móvil.

## No negociables

- Nunca mostrar días perdidos, deuda, racha rota ni urgencia artificial.
- No asumir por sí mismo por qué la persona se ausentó.
- El título debe identificar claramente la sección y la acción debe comunicar cuando está procesándose.
- Una sola salida primaria: elegir cómo retomar.

## Libertad de rediseño

Puede ser tarjeta, banner o sección inicial. Debe sentirse cálido dentro de Aurora 2, usando el tratamiento coral y ámbar reservado para el regreso.
