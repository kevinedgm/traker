# Elemento: selector de energía

## Objetivo

Permitir que la persona estime la energía disponible sin convertirla en una evaluación moral o de productividad.

## Debe mostrar

- Una pregunta o etiqueta que explique qué se está eligiendo.
- Tres opciones mutuamente excluyentes: «Mínimo», «Habitual» y «De sobra».
- Una selección actual claramente visible.

## Estados a diseñar

- Ninguna opción explícitamente elegida al iniciar, si el flujo lo decide.
- Bajo, medio y alto seleccionados.
- Foco de teclado.
- Ancho estrecho y texto ampliado.

## Accesibilidad

- Debe funcionar como una selección única.
- La selección requiere texto o forma además de color.
- Cada opción necesita un área táctil amplia.
- Flechas o Tab/Espacio deben producir una interacción predecible.

## Libertad de rediseño

Puede ser segmentado, tarjetas o radios. No usar metáforas de rendimiento, puntuaciones, llamas ni lenguaje de capacidad personal; describe únicamente energía disponible para esta acción.
